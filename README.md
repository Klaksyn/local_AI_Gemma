# What is it?
It's a local AI by Google (Gemma) controlled via Python.

# PC requirements
Running Gemma 4 E4B smoothly with standard 4-bit compression requires a minimum of 6 GB of system RAM or 4 to 5 GB of VRAM.
**Minimum System Requirements:**
- GPU (VRAM): 4 GB to 5 GB
- System RAM: 8 GB (for 4-bit models)
- CPU-Only Operation: 8-core processor with 16 GB of RAM
- Storage Space: ~3 GB to 8 GB depending on the precision level
