# ДОКУМЕНТАЦИЯ: КАК ЗАПУСТИТЬ ЛОКАЛЬНЫЙ ИИ Gemma 4b

1) Скачайте и установите Ollama с [официального сайта](https://ollama.com)
2) Запустите модель (введите эту команду в PowerShell / CMD / Терминал):
```bash
ollama run gemma4:e4b
```
3) Установите библиотеку для работы с Gemma 4 в Python:
```bash
pip install langchain-ollama
```
4) Наслаждайтесь!
