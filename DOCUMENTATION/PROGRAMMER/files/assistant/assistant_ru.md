# Класс assistant

## Расположения
`assistant/assistant.py`

## Методы

### `ask(text: str) -> str`
Отправляет промпт локальной модели Gemma и выводит ответ в консоль в режиме реального времени.

* **Параметры:**
  * `text` (`str`): Промпт или вопрос, который нужно отправить ИИ.
* **Возвращает:**
  * `str`: Полный текст ответа или сообщение `"stopped by user"`, если генерация была прервана.
* **Особенности:**
  * Потоковый вывод чанков (`flush=True`).
  * Мгновенная остановка при нажатии клавиши **`Alt`** во время генерации.
  * Обработка исключений для прерывания с клавиатуры (`Ctrl+C`) и ошибок во время выполнения.
